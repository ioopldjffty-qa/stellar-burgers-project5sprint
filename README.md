# Проект Sprint_5: Автотесты Stellar Burgers (Selenium + Pytest)

Автоматизированное тестирование космического фастфуда «Stellar Burgers». Проверены сценарии регистрации, авторизации четырьмя способами, выхода из аккаунта и навигации между разделами конструктора.

## Структура проекта
*   **pages/stellar_locators.py**: все локаторы элементов сайта с комментариями.
*   **utils/generators.py**: генерация уникальных данных (почты/пароля) строго по формату задания.
*   **tests/** — тесты разбиты на файлы по функциональности:
    *   **conftest.py**: фикстура открытия браузера и статичные данные пользователя.
    *   **test_registration.py**: успешная регистрация нового пользователя и проверка ошибки короткого пароля (<6 символов).
    *   **test_login_flows.py**: вход в аккаунт четырьмя способами (*через кнопку в шапке, ссылку под формой регистрации, форму восстановления пароля и прямую ссылку Личного кабинета*).
    *   **test_navigation.py**: переходы между вкладками Конструктора («Булки», «Соусы», «Начинки») и возврат к конструктору из личного кабинета.
    *   **test_exit_account.py**: выход из аккаунта и проверка редиректа обратно на страницу входа.

## Запуск тестов
Для работы требуется установленный ChromeDriver.

1.  Активируйте виртуальное окружение:
    ```bash
    .\venv\Scripts\Activate.ps1
    ```
2.  Установите зависимости:
    ```bash
    pip install -r requirements.txt
    ```
3.  Запустите все тесты:
    ```bash
    pytest -v --driver Chrome
    ```
4.  Или запустите конкретный тест:
    ```bash
    pytest tests/test_registration.py::test_successful_registration -v
    ```

> Данные для входа (`email`, `password`) хранятся в файле `. \tests\conftest.py`. Их нужно менять при каждом новом спринте.

## Технический стек
*   Язык: Python 3.x
*   Тестовый фреймворк: Pytest
*   Инструмент автоматизации: Selenium WebDriver
*   Браузер: Google Chrome
*   Драйвер-менеджер: Selenium Manager (автоматическое скачивание драйверов)
